5 · Génération d'une ligne (JS échappé)

Une .mdnd-init-row par combattant. Valeurs dynamiques via escapeHtml(), notes via formatDescription(). Tri init décroissant côté données avant rendu.

// c = { id, nom, type:'pc'|'monster', init, pv, pvMax, ca, etats:[], actif, ko }
function renderRow(c) {
  const pct  = Math.max(0, Math.min(100, c.pv / c.pvMax * 100));
  const bar  = pct <= 25 ? 'is-low' : pct <= 50 ? 'is-mid' : '';
  const badge= c.type === 'pc' ? 'mdnd-badge--info' : 'mdnd-badge';
  const lbl  = c.type === 'pc' ? 'Héros' : 'Monstre';
  const chips= c.etats.map(e =>
    `<span class="mdnd-chip">${escapeHtml(e)} <button type="button" aria-label="Retirer">✕</button></span>`).join('');

  return `
  <div class="mdnd-init-row ${c.actif ? 'is-active' : ''} ${c.ko ? 'is-ko' : ''}" data-id="${c.id}">
    <div class="mdnd-init-num"><input class="mdnd-input" type="number" value="${c.init}"></div>
    <div class="mdnd-init-main">
      <div class="mdnd-init-name">
        <span class="mdnd-init-name__text">${escapeHtml(c.nom)}</span>
        <span class="mdnd-badge ${badge}">${lbl}</span>
        ${c.ko ? '<span class="mdnd-badge mdnd-badge--danger">K.O.</span>' : ''}
      </div>
      <div class="mdnd-chip-list">${chips}<button class="mdnd-chip-add" type="button">+ État</button></div>
    </div>
    <div class="mdnd-hp">
      <div class="mdnd-line-total"><span class="mdnd-line-total__label">PV</span><span class="mdnd-line-total__value">${c.pv} / ${c.pvMax}</span></div>
      <div class="mdnd-hp-bar ${bar}"><i style="width:${pct}%"></i></div>
      <div class="mdnd-hp-actions">
        <button class="mdnd-button mdnd-button--danger" type="button">−</button>
        <input class="mdnd-input mdnd-hp-input" type="number" placeholder="0">
        <button class="mdnd-button mdnd-button--secondary" type="button">+</button>
      </div>
    </div>
    <div class="mdnd-stat"><span class="mdnd-stat__label">CA</span><span class="mdnd-stat__value">${c.ca}</span></div>
    <div class="mdnd-init-actions">
      <button class="mdnd-button mdnd-button--secondary" type="button" title="Détails">⋯</button>
      <button class="mdnd-button mdnd-button--secondary" type="button" title="Retirer">✕</button>
    </div>
  </div>`;
}

6 · Périmètre

  • Pas de React ni build — markup + CSS vanilla, rendu par innerHTML échappé.
  • Pas d'asset binaire — icônes = glyphes texte (‹ › − + ✕ ⋯), remplaçables par tes SVG.
  • Pas de nouveau préfixe — tout sous .mdnd-* ; bloc (A) du CSS à supprimer à l'intégration.
  • Détail d'un combattant : réutilise la modale partagée, mêmes champs que la ligne (nom, init, PV, CA, états).
